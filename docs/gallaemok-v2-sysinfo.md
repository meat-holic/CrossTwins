# 갈래목 v2 시스템 정보

갈래목 홈 화면의 `sysinfo` 블록은 홈 화면에 들어오거나 다른 화면에서 돌아올 때 갱신됩니다. 홈 화면에 머무르는 동안 주기적으로 측정하거나 다시 그리지 않습니다.

| 항목 | 의미 |
| --- | --- |
| `FREE` | 내부 바이트 접근 가능 힙의 현재 가용량입니다. 선택형 PSRAM은 포함하지 않습니다. |
| `MAX` | `FREE`와 같은 힙에서 한 번에 할당할 수 있는 가장 큰 연속 블록입니다. |
| `TEMP` | SoC 내부 온도 센서 값이며 주변 기온이 아닙니다. 센서가 지원되지 않거나 측정에 실패하면 `N/A`로 표시합니다. |
| `CPU` | 화면 진입 시 조회한 현재 CPU 주파수입니다. |
| `UP` | ESP-IDF RTC 카운터를 `HH:MM:SS`로 표시한 경과 시간입니다. 벽시계 시각이 아니며 RTC 유지 상태가 유효하면 딥슬립 시간도 포함될 수 있습니다. |
