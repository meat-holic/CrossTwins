# CrossTwins v1.6.5-ct.7

두 개 이상의 블루투스 페이지 터너(리모컨)를 페어링했을 때 발생할 수 있는 비정상적인 재연결 문제를 수정했습니다.

- 기본 재연결 정책에서 저장된 리모컨을 순서대로 시도하여, 마지막으로 페어링한 리모컨이 꺼져 있어도 다른 리모컨에 연결할 수 있습니다.
- 명시적으로 선택한 리모컨에 연결하는 기존 정책을 유지합니다.
- 블루투스 시작 중 상태 표시와 폰트 캐시 해제 전후의 메모리 진단 로그를 개선했습니다.

X4에서 BOOX Keypage와 MITER_BTR을 함께 페어링하고, MITER_BTR 전원 OFF·BOOX Keypage 전원 ON 상태의 재연결 및 정상 작동을 사용자 실기기 검증으로 확인했습니다. 이 검증은 `3bb23622`의 default 빌드에 대한 결과입니다. 다른 기기의 빌드 성공은 실기기 검증을 뜻하지 않습니다.

공식 대상은 X3/X4, Sticky, X4 Pro, X4 Classic, Paper Mono입니다. BLE 포함 여부는 각 기기의 기존 빌드 설정을 따릅니다.

자산 이름의 `crosspoint-…-<기기>.bin`은 앱 업데이트 이미지, `CrossPoint-…-<기기>-full.bin`은 bootloader·partition을 포함하는 full-flash 이미지입니다. 실험용 BLE OFF 비교 바이너리는 배포 자산에 포함하지 않습니다.

기여: [eunchurn의 PR #2](https://github.com/meat-holic/CrossTwins/pull/2). 원본 커밋과 작성자 이력을 보존했습니다.

내부 품질 개선: Host 회귀 테스트의 임시 파일을 테스트·프로세스별로 격리했습니다.
