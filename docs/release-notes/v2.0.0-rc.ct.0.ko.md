# CrossTwins-2.0.0RC-ct.0

CrossPoint 2.0.0RC를 CrossTwins의 기존 독서 구조에 통합한 **Pre-release**입니다. 정식 Latest 릴리스가 아니며, 전체 실기기 안정성 검증은 아직 완료되지 않았습니다.

- 한국어 줄바꿈·문단 설정, SD 폰트, TXT 온디맨드 읽기, Lyra 진행도·챕터 표시와 BLE 재연결 정책을 유지합니다.
- SD 폰트 재검색 시 이전 목록의 예약 공간을 해제하고, EPUB 페이지·anchor 저장소의 큰 연속 할당을 줄였습니다. 유휴 시간에 챕터 페이지 생성을 이어가며 입력이 대기하면 중단합니다. 실기기 힙 개선 수치는 아직 측정하지 않았습니다.
- OTA 조회·다운로드에 CA 체인과 호스트명 검증, HTTPS 전용 redirect 정책을 추가했습니다. 인증 실패 시 검증을 해제하여 재시도하지 않습니다. 기존 OPDS/KOSync의 인증 정책은 이번 변경으로 바꾸지 않았습니다.
- 다운로드 파일 닫기 실패 시 기존 파일을 교체하지 않도록 했습니다.
- upstream PR #4126의 CJK break-offset 계산을 선별 이식하여 단어별 임시 staging vector를 제거했습니다. CT의 한국어 경계 판단·토큰화·캐시 형식은 유지하며, 업스트림의 별도 명시적 하이픈 토큰화 기능은 도입하지 않았습니다. CrossTwins의 실기기 할당 횟수·속도 개선 수치는 측정하지 않았습니다.
- **하이프네이션 기본값이 ON**입니다. 신규 설치와 저장 항목이 없는 경우에만 새 기본값을 사용합니다. 기존 설정 파일의 명시적 OFF/ON은 유지하며 강제 초기화하지 않습니다. 설정 화면에서 계속 변경할 수 있습니다. EPUB의 기존 하이프네이션과 TXT의 한국어 줄 끝 분할에 적용하며, TXT에 영어 패턴 하이프네이션이나 균등정렬을 새로 도입하지 않습니다.

내부 버전은 `2.0.0-rc.ct.0+<source SHA>`, 태그 규칙은 `v2.0.0-rc.ct.0`입니다. 표시명과 내부 SemVer를 구분합니다.

공개 게이트는 전체 Host 회귀, 릴리스 계약, 공식 5환경(X3/X4·Sticky·X4 Pro·X4 Classic·PaperMono) 빌드 및 이미지 검사, SDK 원격 재현성, 동일 HEAD의 GitHub CI와 preflight/seal, 14개 자산·체크섬 검증입니다. 세부 결과와 소스 SHA는 GitHub Actions 및 첨부 SHA256SUMS를 확인하세요.

**미검증·알려진 위험:** 최종 RC의 실제 기기 TLS, 장시간 C3 heap/fragmentation, S3 PSRAM 압박, SD 오류·전원 차단, BLE sleep/wake·복수 bond, 한국어 화면 품질은 HARDWARE_PENDING입니다. 과거 X4 기본 동작 확인은 이번 최종 RC의 검증으로 간주하지 않습니다. 과거 OTA 0% 실패 원인은 UNVERIFIED이며 TLS 수정으로 해결되었다고 주장하지 않습니다. CA 체인·호스트명·시각·메모리 부족으로 인증이 실패하면 OTA도 실패 처리하며 검증을 우회하지 않습니다. 기존 OPDS/KOSync의 insecure TLS 정책은 이번 변경으로 개선되지 않았습니다. 프리릴리스의 자동 OTA 검색·설치를 보장하지 않으며 강제 OTA 배포는 수행하지 않습니다.
