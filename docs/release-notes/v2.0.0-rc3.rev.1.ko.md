# CrossTwins v2.0.0-rc3.rev.1

이 릴리스는 기존 CrossPoint Reader RC3 업데이트를 반영한 시험판 개정입니다. 지원 기기별 새 펌웨어 바이너리와 체크섬 매니페스트를 제공합니다.

## 신규 테마 추가

- MS-DOS 콘셉트의 **갈래목(Gallaemok DOS)** 테마를 추가했습니다.
- DOS 스타일 홈 화면에서 최근 도서와 EPUB 진행률을 표시합니다.
- 기존 Lyra 및 Lyra Extended 테마도 계속 선택할 수 있습니다.

## SD 카드 UI 글꼴 지원

- SD 카드의 `.cpfont`를 시스템 UI 글꼴로 선택할 수 있습니다.
- Reader 본문 글꼴과 시스템 UI 글꼴 설정은 서로 독립적입니다.
- UI 글꼴 선택 목록에는 경로와 `.cpfont` 확장자를 제외한 이름을 표시합니다.
- SD 글꼴을 사용할 수 없으면 기본 UI 글꼴로 대체합니다.

## 추가 다운로드: 삼국지3글꼴 기반 CPFont

삼국지3 스타일의 한글 글꼴을 CrossTwins용 CPFont로 변환한 선택 설치 패키지입니다.

**첨부 파일:** `Sam3KRFont-CPFont.zip`

원본 Sam3KRFont에는 한자가 포함되어 있지 않습니다. ZIP에는 Reserved Font Name 문구를 포함한 원본 MIT 라이선스 전문을 그대로 동봉합니다.

포함 글꼴:

- `Sam3KRFont_10.cpfont`
- `Sam3KRFont_11.cpfont`
- `Sam3KRFont_12.cpfont`
- `Sam3KRFont_13.cpfont`

### 설치 방법

1. `Sam3KRFont-CPFont.zip`을 내려받고 압축을 풉니다.
2. 안의 `Sam3KRFont` 폴더를 SD 카드의 `/.fonts` 디렉터리에 복사합니다.
3. 설정의 **UI 글꼴**을 **SD 카드 글꼴**로 설정합니다.
4. **UI 글꼴 선택**에서 원하는 `Sam3KRFont` 파일을 선택합니다.

본문용 Reader 글꼴 선택은 이 설정과 별도로 유지됩니다.

## 펌웨어 설치 및 업데이트 주의

- 기기에 맞는 파일을 사용하세요. `x3-x4`는 X3와 X4용이며, 나머지는 `sticky`, `x4pro`, `x4c`, `papermono` 자산을 해당 기기에 사용합니다.
- USB 플래싱이 잠긴 기기는 [README의 설치 안내](https://github.com/meat-holic/CrossTwins#usb-locked-devices-xteink-unlocker)를 먼저 확인하세요. Xteink Unlocker에서 공식 지원하는 펌웨어는 CrossPoint와 CrossInk이며, 다른 펌웨어 설치는 기기 복구를 어렵게 할 수 있습니다.
- 이 개정판은 시험판(prerelease)이며 내장 OTA 검사에서 자동으로 제공되지 않습니다. 시험판을 설치하려면 기기에 맞는 `.bin`을 [웹 설치기](https://crosspointreader.com/#flash-tools)에서 수동으로 선택하세요. 자세한 이유는 [GitHub의 `releases/latest` 동작 설명](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)을 참고하세요.
- 설치 중에는 기기의 전원을 끄지 마세요.
